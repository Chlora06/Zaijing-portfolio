# Zaijing Liu — UX Research Portfolio

A minimal, static multi-page portfolio site. No framework, no build step —
plain HTML + one shared stylesheet. Open `index.html` in a browser to view.

## Pages
| File | Page |
|------|------|
| `index.html` | Home — intro + project index |
| `about.html` | About (typed headline) |
| `resume.html` | Resume (embedded PDF preview + download) |
| `safeway.html` | Project 01 — Redesigning the Safeway Mobile App |
| `meetup.html` | Project 02 — Usability Testing for the Meetup Website |
| `wearables.html` | Project 03 — Wearable Takeover-Request Interfaces |
| `styles.css` | Shared design system + all components |

## Assets
- `images/` — photos and screenshots
- `assets/` — supporting documents
- `Zaijing-Liu-Resume.pdf` — résumé (linked from the Resume page)

## Run locally
Just open `index.html` — everything works from `file://`.
For live-reload while editing, use the VS Code **Live Server** extension
(right-click `index.html` → *Open with Live Server*).

## Archive
`archive/` holds the previous design portfolio (Home / About me / Blog /
Designs) and the original Claude-design export, kept for reference.
