ChronoSencse

Figbuild Hackathon 2026

ChronoSense is a speculative UX project that explores how technology might make subjective time perception visible. Instead of focusing on schedules or productivity, the concept uses simulated neural signals to visualize attention states—such as focus, distraction, and stagnation—helping users better understand how they experience time. By introducing subtle, non-intrusive interventions, the system aims to support awareness rather than control, reframing time not as something to manage, but as something to perceive.

Match Dog

Project duration:Jan 2026 - March 2026

This project focuses on the Admin (B2E) system for MatchDog, supporting core operations such as animal records, user management, and the adoption process. Using a conceptual model approach, I translated complex workflows into an Object-Action-Attribute grammar and applied prioritization and user flows to streamline task efficiency. The design aims to reduce cognitive load, support multitasking, and create a clear, scalable admin experience.
